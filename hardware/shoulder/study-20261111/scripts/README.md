# Shoulder study scripts

Run in order from one scratch folder (they read and write relative paths there): `torso.py` (extracts cage and pitch parts
from `TORSO.step`), `mesh.py` (places the shoulder STEPs in the torso frame), `sweep.py` then `fixsplit.py` (surface samples,
rotor/stator split), `gaps.py`, `sweep2.py pitch|roll|yaw`, `room.py`, `sect.py`, `holes.py`, `hx.py`, `cyl.py`, and
`rv.py`/`secimg.py`/`secs.py`/`r5.py` for the pictures. Input paths are absolute paths on Joey-PC in each script's header.
